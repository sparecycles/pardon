## gRPC Support

Pardon has initial support for (non-streaming) gRPC calls.
The gRPC protocol is similar enough to http that we can use HTTP
syntax to represent a simple gRPC call: the method being called can be
represented with the path, any metadata can be specified as request headers,
and the argument to the call is specified as the request body.

We use the http verb `RPC` to select the `gRPC` transport:

```http
RPC https://service.example.com/package.Service/Method
Metadata: value

{ ... }
```

Secure calls are specified with `https:` and insecure calls
can be made with `http:` in the URL protocol.

Your service collecton must also have entries describing the protocols in `.https` files:

```yaml
protocols:
 - path/to/protocol.proto
```

These are loaded when a gRPC call is attempted.

:::note
Using gRPC currently skips the default undici implementation
for the request: disabling the DNS resolution override.
:::
